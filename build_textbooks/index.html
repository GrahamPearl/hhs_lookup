Step 3 — Minimum Firestore security rules

Paste these into Firebase Console → Firestore → Rules. They allow authenticated users to read/write the allocations and students collections. Tighten before production. 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /allocations/{docId} {
      allow read, write: if request.auth != null;
    }
    match /students/{admnr} {
      allow read, write: if request.auth != null;
    }
  }
}

⚠ For this prototype without Auth, temporarily set if true; during initial testing, then re-add auth requirements.
